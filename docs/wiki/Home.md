# project-template

The starting point for every metalayerlab project: one command gives a new repository our CI/CD, release automation, container image, deployment manifests, a standardised wiki and instructions for AI assistants. `copier update` keeps it in step with the template afterwards.

```sh
uvx copier copy --trust gh:metalayerlab/project-template my-project
```

It is built for **AI-generated, human-reviewed** code. The template supplies the rails (checks, conventions, docs structure, review checklist), the assistant builds within them, and a human approves every change.
